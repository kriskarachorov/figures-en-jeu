Une précision sur le cours

La fiche utilise « paradiastole » pour un alignement de segments parallèles. Cet emploi diffère de la définition rhétorique habituelle. Le jeu conserve cette entrée avec la mention « selon ta fiche » ; confirme le terme attendu avec ton professeur. Voir le dictionnaire de l’argumentation de Christian Plantin (CNRS). L’isotopie est un procédé sémantique. Les exemples peuvent combiner plusieurs procédés : le jeu demande celui indiqué par l’indice.
