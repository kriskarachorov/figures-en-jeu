# Figures en jeu

Jeu de révision en français : 32 figures de style, entraînement avec indices, contrôle blanc et fiches mémo.

Ouvrir `index.html` dans un navigateur. Aucun compte ni installation nécessaire. Les réponses ne sont pas envoyées à un serveur.

Le terme « paradiastole » est repris de la fiche de cours avec une précision dans le jeu : cet emploi est à confirmer avec le professeur.
